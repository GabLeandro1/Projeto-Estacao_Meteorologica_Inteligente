# 🌤️ Estação Meteorológica Inteligente

<p align="center">
  Sistema desenvolvido para monitoramento, coleta, visualização e análise de dados meteorológicos por meio de uma estação simulada na plataforma Wokwi, integrada a uma página web e a um dashboard desenvolvido em Python.
</p>

---

## 📌 Sobre o Projeto

A **Estação Meteorológica Inteligente** é um projeto desenvolvido com o objetivo de coletar, organizar e facilitar a análise de informações relacionadas às condições climáticas de um determinado ambiente.

O sistema utiliza uma estação meteorológica construída e simulada na plataforma **Wokwi**, responsável pela obtenção de dados como temperatura, umidade, pressão atmosférica, luminosidade e incidência de chuva.

Para facilitar a interpretação dessas informações, foram desenvolvidas duas interfaces de visualização:

- **Página Web:** permite consultar e visualizar os dados meteorológicos por meio de gráficos interativos.
- **Dashboard em Python:** apresenta os registros coletados em uma interface gráfica, possibilitando a análise individual de cada variável meteorológica.

O projeto busca tornar o acompanhamento das condições climáticas mais acessível, organizado e intuitivo.

## ✨ Funcionalidades

- Coleta de informações meteorológicas por meio de uma estação simulada no Wokwi.
- Monitoramento de temperatura e umidade.
- Acompanhamento da pressão atmosférica.
- Registro de luminosidade e incidência de chuva.
- Visualização dos dados por meio de gráficos.
- Análise individual das variáveis meteorológicas no dashboard em Python.
- Interface web intuitiva para facilitar a consulta das informações.

## 🚀 Como Executar o Projeto

### 1. Clonar o repositório

Abra o terminal e execute:

```bash
git clone https://github.com/GabLeandro1/Projeto-Estacao_Meteorologica_Inteligente.git
```

### 2. Acessar a pasta do projeto

```bash
cd Projeto-Estacao_Meteorologica_Inteligente
```

### 3. Executar a página Web

Abra o arquivo `index.html` em seu navegador ou utilize a extensão **Live Server** no Visual Studio Code para executar a página localmente.

### 4. Executar o Dashboard em Python

Certifique-se de ter o Python instalado em seu computador e execute:

```bash
python dashboard.py
```

Caso existam bibliotecas externas necessárias, instale-as antes da execução.

## 🎯 Objetivo do Projeto

O desenvolvimento deste projeto busca aplicar conhecimentos de programação, desenvolvimento web e análise de dados na construção de uma solução voltada ao monitoramento meteorológico.

Além disso, procura demonstrar como a integração entre simulação de hardware, desenvolvimento de interfaces e visualização de dados pode contribuir para tornar o acompanhamento de informações ambientais mais eficiente e acessível.
